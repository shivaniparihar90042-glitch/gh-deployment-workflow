# GitHub Actions Automated Deployment

## Project Overview

This project demonstrates how to automatically deploy
a website using GitHub Actions and GitHub Pages.

## Objective

To automate website deployment whenever index.html
is updated and pushed to the main branch.

## Technologies Used

- HTML
- Git
- GitHub
- GitHub Actions
- GitHub Pages

## How It Works

1. Create a website using HTML.
2. Push the project to GitHub.
3. GitHub Actions checks for changes in index.html.
4. If index.html changes, deployment starts.
5. GitHub Pages publishes the updated website.

## Project Structure

- index.html - Website
- README.md - Project documentation
- .github/workflows/deploy.yml - Automation workflow

## Expected Result

The website should automatically deploy when
index.html changes.

Changes to README.md alone should not trigger deployment.
